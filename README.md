# StDistro - ERP System

Solución integral diseñada para optimizar la gestión operativa de distribuidoras de bebidas. El sistema centraliza el control de inventario, la gestión de pedidos y la visualización de datos comerciales.

### Características Principales:

Gestión de Inventario: Control de stock en tiempo real con alertas de reposición.

Lógica de Ventas: Procesamiento de pedidos y vinculación con bases de datos de clientes.

Arquitectura Robusta: Integración eficiente de base de datos para asegurar la consistencia de la información.

### Stack Tecnológico:

Frontend: React, Tailwind CSS.

Backend/Lógica: JavaScript / TypeScript.

Base de Datos: Supabase SQL (PostgreSQL/MySQL).
